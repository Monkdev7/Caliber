## 📞 FAQ

### Q: How do I get started?

A: Read `START_HERE.md`, then run `npm install && npm run dev`

### Q: Where do I change the API URL?

A: Edit `.env.local` - change `VITE_API_URL`

### Q: How do I add new filters?

A: See `FRONTEND_QUICK_REFERENCE.md` - Customization section

### Q: What if styling doesn't work?

A: See `FRONTEND_SETUP.md` - Troubleshooting section

### Q: How do I deploy?

A: See `FRONTEND_SETUP.md` - Production Build section

### Q: Can I customize the design?

A: Yes! Edit `tailwind.config.js` for colors/theme

### Q: What's the file structure?

A: See `VISUAL_SUMMARY.md` or `FRONTEND_ARCHITECTURE.md`

### Q: How do I debug?

A: Use browser DevTools (F12) and React DevTools extension
